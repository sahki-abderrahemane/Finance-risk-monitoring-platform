# Sentinel-AI Visual Identity System

## 1. Overview

Sentinel-AI is a research and risk-monitoring platform for financial intelligence. The identity should feel enterprise-grade, technical, and precise, while still remaining modern and usable in a mobile application.

This system is designed to communicate:

- intelligence
- financial risk monitoring
- security and trust
- simulation and experimentation
- explainability and evidence

### Core brand statement

Sentinel-AI = Dark Navy + Electric Blue + Teal + Inter + Data Visualization + Shield/Radar/Neural Motifs + Evidence-Driven AI

### Tagline

Research • Simulate • Understand

---

## 2. Brand Concept

### Brand name

Sentinel-AI

### Strategic meaning

The word “Sentinel” is central to the brand. A sentinel is a watcher, guardian, and monitor. That aligns directly with the product’s purpose: understanding and monitoring financial risk rather than executing trades.

The visual identity should avoid looking like a typical stock-trading app.

### Avoid

- Buy/Sell buttons
- Aggressive green/red trading aesthetic
- Cryptocurrency-style visuals
- Excessive candlestick charts
- Profit-focused messaging
- Luxury-finance aesthetics

### Emphasize

- Risk
- Monitoring
- Evidence
- Models
- Simulation
- Explainability
- Confidence
- Data
- Security
- Research

---

## 3. Visual Direction

The design should feel like a digital command center for understanding risk.

The dominant visual relationship should be:

Deep Navy → Blue → Cyan/Teal

This should feel disciplined and professional rather than rainbow-like or high-noise.

## 5. Typography

The type system should be clean, modern, and technical.

### Primary font

Inter

Use Inter throughout the application, especially in the mobile UI.

### Recommended hierarchy

| Style | Size | Weight |
|---|---:|---|
| Display | 32–36 px | Bold |
| H1 | 26–30 px | Bold |
| H2 | 20–24 px | SemiBold |
| H3 | 16–18 px | SemiBold |
| Body | 14–16 px | Regular |
| Caption | 11–13 px | Medium |
| Data | 14–16 px | SemiBold |

### Numerical metrics

Numerical values should use Inter SemiBold/Bold for emphasis.

Example:

72
HIGH RISK

The number should visually dominate the label.

### Optional technical font

For model IDs, timestamps, API-like metadata, and technical details, a monospace font such as JetBrains Mono may be used sparingly.

Example:

MODEL  risk-gbm-v1.2
RUN    #8F31A2
DATA   OHLCV_2025

This introduces an MLOps and engineering character without overloading the interface.

## 6. Logo Direction

The logo should be grounded in the concept of a modern digital sentinel.

### Recommended structure

- Symbol + wordmark

### Symbol concept

A minimal geometric shield combined with:

- an eye
- radar
- neural node
- monitoring signal

Conceptually:

```text
       ◇
    ╱     ╲
   │   •   │
   │  ╱╲   │
    ╲_____╱
```

The symbol should not look like a medieval shield. It should feel like a modern AI monitoring node.

### Wordmark options

- SENTINEL / AI
- Sentinel-AI

The “AI” portion can be highlighted in blue/teal for contrast and emphasis.

```text

│  RISK SCORE                 │
│                             │
│       72                    │
│       HIGH                  │
│                             │
│  ────────────────╱──        │
│                             │
│  Volatility      68%        │
└─────────────────────────────┘
```

### Use

- Dark navy surface
- 1 px subtle border
- 12–20 px radius
- Soft shadow
- 16–20 px internal padding

### Avoid

- Overly glassy cards
- Gaming-inspired visuals
- Heavy neon or dramatic gradients

The app should feel like a professional analytical instrument, not a trading game.

### Chart style

- Main series: Electric blue / cyan
- Secondary series: Teal / muted blue
- Risk thresholds: Amber / orange / red

### Example

- Use minimal gridlines

## 10. Risk Score Visualization

This should become a signature Sentinel-AI component.

### Risk ring concept

```text
          ╭────────╮
       ╭──╯        ╰──╮
      │       72       │
      │      HIGH      │
       ╰──╮        ╭──╯
          ╰────────╯
```

The ring can dynamically transition through:

Teal → Amber → Orange → Red

depending on the score.

### Underneath the ring

- Risk Score
- 72 / 100
- ↑ 8.4% vs previous period

The interface should clearly indicate that this is a model-generated risk measure, not an investment recommendation.

## 12. RAG Visual Identity

The RAG interface should feel evidence-driven and grounded in retrieved sources.

### Example

```text
AI EXPLANATION

Risk increased because volatility
and liquidity indicators deteriorated.

────────────────────────────

EVIDENCE

[01] Financial Report
     Retrieved evidence

[02] Economic Report
     Retrieved evidence

[03] Market News
     Retrieved evidence
```

### Principle

Each source should carry a provenance indicator.

Recommended model:

Source → Chunk → Explanation

This reinforces the key Sentinel-AI principle:

The LLM explains the model output; it does not create the prediction.

---

## 13. Explainability Identity

SHAP/LIME screens should use a scientific and analytical aesthetic.

### Example

```text
WHY IS RISK HIGH?

Volatility       ████████████  +24
Liquidity        ████████      +16
Momentum         █████         +11
RSI              ███            +7
Volume           ██             +4
```

### Accessibility guidance

Positive and negative contribution should be distinguishable without relying only on color.

Use:

- arrows
- +/- symbols
- labels
- magnitude

This improves clarity and accessibility.

## 16. Background Treatment

The background should remain mostly dark.

### Recommended base

- Base: #07111F

Then add subtle radial or linear gradients around high-priority content areas.

Example:

```text
       cyan glow
           ↓
      ╭──────────╮
      │ Risk 72  │
      ╰──────────╯
```

### Design note

The glow should be subtle and restrained. No excessive neon.

The goal is:

Bloomberg / enterprise analytics + modern AI

rather than:

Cyberpunk trading app.

---

## 17. Borders and Shadows

Use very subtle borders:

- border: #243449

### Border radius

- Small: 8 px
- Medium: 12 px
- Large: 20 px

Shadows should be soft and low-opacity.

Cards should be defined primarily through surface contrast rather than huge shadows.

---

## 18. Buttons

### Primary button

```text
┌────────────────────┐
│  Run Analysis  →   │
└────────────────────┘
```

- Blue filled button

### Secondary button

```text
┌────────────────────┐
│  View Explanation  │
└────────────────────┘
```

- Dark surface + border

### Destructive button

Use only for actions such as:

- Delete simulation
- Reset configuration
- Remove dataset

Never use destructive styling for ordinary risk states.

---

## 19. Motion Design

The app should feel alive but controlled.

### Recommended animation patterns

- Risk score: number counts animate in sequence
- AI analysis: subtle scanning motion
- Charts: data lines render progressively
- RAG: evidence sources appear in sequence

### Example motion sequence

```text
0 → 23 → 48 → 65 → 72
```

```text
●────●────●
     ↓
   scanning
```

```text
Retrieving...
      ↓
3 sources found
      ↓
Evidence grounded
      ↓
Explanation generated
```

### Timing

- Normal interaction duration: 150–300 ms
- Avoid long animations

---

## 20. Empty States

Empty states should reinforce the platform’s research and simulation nature.

### Avoid

- “No portfolio yet.”

### Preferred

- “No simulation configured”
- “Create a historical or synthetic scenario to begin your analysis.”

This language is more aligned with Sentinel-AI.

---

## 21. Status Language

Use precise technical terminology.

### Preferred status labels

- Model Ready
- Data Validated
- Risk Computed
- Evidence Retrieved
- Simulation Running
- Model Drift Detected
- Explanation Grounded
- Historical Dataset
- Synthetic Dataset

### Avoid

- Buy Now
- Sell
- Guaranteed
- Best Investment
- Expected Profit
- AI Recommendation

This is especially important because Sentinel-AI is explicitly a research, simulation, and risk-monitoring platform.

## 23. Overall Visual Personality

The identity can be defined with five words:

- Precise
- Intelligent
- Secure
- Scientific
- Enterprise

### Summary

Sentinel-AI is a dark, precise, evidence-based system for understanding and monitoring risk. It should feel like a professional command center for AI-driven financial analysis, not a consumer trading app.

### Final visual direction

6 / 10

The resulting identity is:

Dark Navy + Electric Blue + Teal + Inter + Data Visualization + Shield/Radar/Neural Motifs + Evidence-Driven AI

### Core design principle

“A digital command center for understanding risk.”

This identity can extend across the mobile app, web dashboard, API surfaces, model monitoring, MLflow, and reporting tools without breaking consistency.
